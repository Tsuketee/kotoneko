# คันจิ N5 🈶

เว็บแอปทบทวนภาษาญี่ปุ่นระดับ N5 ใช้บน iPad ได้เหมือนแอปจริง และเปิดได้ตอนออฟไลน์

## ทำอะไรได้บ้าง
- **คานะ:** ฮิระงะนะ/คะตะคะนะ พร้อมตาราง เคล็ดจำ และเสียงอ่าน
- **คันจิ N5:** 103 ตัว พร้อมตัวอย่างคำที่ใช้คันจินั้น
- **คำศัพท์และบทสนทนา**
- **3 โหมด:** การ์ด · ควิซ · ฝึกเขียนตามลำดับขีด (รองรับ Apple Pencil)
- **ระบบทบทวนแบบเว้นระยะ:** ข้อที่ตอบผิดจะกลับมาให้ทบทวนเร็วขึ้น
- **เพื่อนสัตว์เลี้ยง:** สุ่มนิสัยได้ 10 แบบ มีภารกิจรายวัน, streak และหน้าสถิติ

## โครงสร้างไฟล์
```
index.html              หน้าหลัก (โหลดไฟล์ด้านล่างตามลำดับ)
css/style.css           หน้าตาแอป
js/data/kanji-n5.js     รายการคันจิ N5
js/data/content.js      คำศัพท์และบทสนทนา (เขียนเอง)
js/data/strokes.js      ข้อมูลลำดับขีดสำหรับโหมดฝึกเขียน
js/app.js               ตรรกะทั้งหมดของแอป
sw.js, manifest.webmanifest, icons/   ส่วนของ PWA (ใช้ออฟไลน์ และเพิ่มลงหน้าจอโฮม)
docs/ROADMAP.md         รายการงานที่จะทำต่อ
CLAUDE.md               คำสั่งสำหรับ Claude Code
```

## ลองเปิดในเครื่อง
```
python3 -m http.server
```
แล้วเปิด http://localhost:8000

## เผยแพร่
repo นี้เป็นแบบ private บัญชี GitHub ฟรีจะใช้ GitHub Pages กับ repo private ไม่ได้ มีทางเลือก 2 ทาง
1. **Cloudflare Pages (แนะนำ):** ฟรี ใช้กับ repo private ได้ เชื่อมกับ GitHub แล้วไม่ต้องตั้งค่าการ build (Build command เว้นว่าง, Output directory = `/`)
2. **GitHub Pages:** ต้องเปลี่ยน repo เป็น public ก่อน

ได้ลิงก์แล้ว ให้เปิดใน Safari บน iPad → กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

> ความคืบหน้าจากเวอร์ชันเก่า (artifact บน claude.ai) จะไม่ย้ายมาเอง เพราะเก็บแยกตามเว็บไซต์ ต้องรอฟีเจอร์ส่งออก/นำเข้าใน ROADMAP เฟส 1

## ปล่อยเวอร์ชันใหม่
ทุกครั้งที่แก้ไฟล์ ให้เพิ่มเลข `VERSION` ใน `sw.js` ไม่งั้นเครื่องที่เคยเปิดแอปแล้วจะยังเห็นไฟล์เก่า

## ทดสอบ
ชุดทดสอบอัตโนมัติ 12 ข้อ (ข้อมูล, การใช้งานหลัก, ส่งออก/นำเข้า, iPad แนวตั้ง/นอน, PWA ออฟไลน์) ใช้ Playwright เปิด Chromium จริง
```
npm install
npx playwright install chromium   # ครั้งแรกครั้งเดียว
npm test
```
ควรรันก่อนปล่อยเวอร์ชันใหม่ทุกครั้ง ส่วนการทดสอบบน iPad Safari จริง (Apple Pencil, safe-area) ยังต้องลองด้วยมือ
