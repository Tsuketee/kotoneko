# Roadmap

ทำทีละข้อ แต่ละข้อควรจบได้ใน 1 เซสชันของ Claude Code
ทำเสร็จแล้วให้เปลี่ยน `[ ]` เป็น `[x]`

## เฟส 1 · ย้ายขึ้น GitHub และใช้บน iPad ได้
- [x] แยกโค้ดจากไฟล์เดียวเป็น `css/`, `js/data/`, `js/app.js`
- [x] ทำเป็น PWA (manifest, service worker, ไอคอน) ให้เพิ่มลงหน้าจอโฮมและใช้ตอนออฟไลน์ได้
- [x] เผยแพร่เว็บ ผ่าน GitHub Pages: https://tsuketee.github.io/kotoneko/ (ดูวิธีใน README หัวข้อ "เผยแพร่")
- [x] เพิ่มปุ่ม "ส่งออก/นำเข้าความคืบหน้า" (ไฟล์ JSON) ในหน้าสถิติ ไว้ย้ายข้อมูลจากเวอร์ชันเก่า และสำรองข้อมูล
- [ ] แยก `js/app.js` เป็นไฟล์ย่อยตามหน้าที่ (เรียน, ฝึกเขียน, สัตว์เลี้ยง, สถิติ) โดยพฤติกรรมเหมือนเดิมทุกอย่าง

## เฟส 2 · เนื้อหา N5 ให้ครบ (เวอร์ชันที่ขายได้)
- [x] เขียนคำศัพท์และบทสนทนา (W, V, D) เองใน `js/data/content.js`: คำศัพท์ N5 และบทสนทนาชีวิตประจำวัน ทั้งแบบสุภาพและกันเอง
- [ ] ตรวจรายการคันจิ N5 ให้ครบ (ปัจจุบันมี 103 ตัว) โดยใช้ข้อมูลเปิด เช่น KANJIDIC2 และใส่เครดิตใน `NOTICE.md`
- [x] ยืนยันแหล่งที่มาของข้อมูลลำดับขีดใน `js/data/strokes.js` แล้วใส่เครดิตให้ถูกต้อง
- [ ] เพิ่มบทเรียนไวยากรณ์ N5 เบื้องต้น
- [ ] ปรับระบบทบทวนแบบเว้นระยะ (ค่า `IV` ใน app.js) ให้เหมาะกับการเรียนระยะยาว

## เฟส 3 · ระบบสัตว์เลี้ยง 2D
- [ ] เปลี่ยนสัตว์เลี้ยงจาก emoji เป็นภาพพิกเซล 2D (อ้างอิงงานออกแบบ "สัตว์เลี้ยงพิกเซล: ชีตแรก")
- [ ] ท่าทางตามอารมณ์และร่างที่โตขึ้นตามความสนิท
- [ ] เพิ่มบทพูดให้ครบนิสัยทั้ง 10 แบบ ในทุกช่วงเวลาและเหตุการณ์
- [ ] ระบบรางวัล: เรียนแล้วได้ของแต่งตัวหรือของตกแต่งให้สัตว์เลี้ยง
