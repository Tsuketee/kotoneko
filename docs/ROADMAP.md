# Roadmap

ทำทีละข้อ แต่ละข้อควรจบได้ใน 1 เซสชันของ Claude Code
ทำเสร็จแล้วให้เปลี่ยน `[ ]` เป็น `[x]`

## เฟส 1 · ย้ายขึ้น GitHub และใช้บน iPad ได้
- [x] แยกโค้ดจากไฟล์เดียวเป็น `css/`, `js/data/`, `js/app.js`
- [x] ทำเป็น PWA (manifest, service worker, ไอคอน) ให้เพิ่มลงหน้าจอโฮมและใช้ตอนออฟไลน์ได้
- [x] เผยแพร่เว็บ ผ่าน GitHub Pages: https://tsuketee.github.io/kotoneko/ (ดูวิธีใน README หัวข้อ "เผยแพร่")
- [x] เพิ่มปุ่ม "ส่งออก/นำเข้าความคืบหน้า" (ไฟล์ JSON) ในหน้าสถิติ ไว้ย้ายข้อมูลจากเวอร์ชันเก่า และสำรองข้อมูล
- [x] แยก `js/app.js` เป็นไฟล์ย่อยตามหน้าที่ (เรียน, ฝึกเขียน, สัตว์เลี้ยง, สถิติ) โดยพฤติกรรมเหมือนเดิมทุกอย่าง

## เฟส 2 · เนื้อหา N5 ให้ครบ (เวอร์ชันที่ขายได้)
- [x] เขียนคำศัพท์และบทสนทนา (W, V, D) เองใน `js/data/content.js`: คำศัพท์ N5 และบทสนทนาชีวิตประจำวัน ทั้งแบบสุภาพและกันเอง
- [x] ตรวจรายการคันจิ N5 ให้ครบ (ตอนนี้มี 105 ตัว) โดยใช้ข้อมูลเปิด เช่น KANJIDIC2 และใส่เครดิตใน `NOTICE.md`
- [x] ยืนยันแหล่งที่มาของข้อมูลลำดับขีดใน `js/data/strokes.js` แล้วใส่เครดิตให้ถูกต้อง
- [x] เพิ่มบทเรียนไวยากรณ์ N5 เบื้องต้น (11 บท)
- [x] ปรับระบบทบทวนแบบเว้นระยะ (ค่า `IV` ใน js/learn.js) ให้เหมาะกับการเรียนระยะยาว

## เฟส 3 · ระบบสัตว์เลี้ยง 2D
- [x] ธีมหลัก "A อาพริคอต" (ส้มพีชอุ่น ครีม เขียวเซจ) ทั้งโหมดสว่างและมืด แยกสีตอบผิดออกจากสีหลัก
- [x] เปลี่ยนอิโมจิทั่วไปเป็นไอคอนโครงเส้นมินิมอล (SVG ใน `js/core.js`) ยกเว้นตัวสัตว์เลี้ยง
- [ ] ธีมประจำฤดูกาล (สีและไอคอนประดับตามฤดู + ประโยคสัตว์เลี้ยงตามฤดู) เก็บไว้ทำภายหลัง
- [ ] สัตว์เลี้ยงเป็นภาพพิกเซล 48×48 วาดต้นฉบับเอง (ตัวป้อมกลมแบบโมจิ ตาเป็นขีด ดีใจเป็นตา > < เส้นขอบน้ำตาลอุ่น) เริ่มจากแมว แล้วกระต่ายและหมาใช้โครงเดียวกัน ร่างอยู่ใน `docs/` เมื่อนิ่งแล้วค่อยใส่ในแอป
- [ ] อารมณ์/ท่าทางของสัตว์เลี้ยง 10 แบบ ขยับ 4 เฟรม: นั่ง ดีใจ ตื่นเต้น เสียใจ นอนหลับ ง่วงหาว กินข้าวปั้น เขินอาย สงสัย รัก ผูกกับเหตุการณ์จริงในแอป (ตอบถูก/ผิด ถึงเป้า หายไปนาน ดึก ให้อาหาร ฯลฯ)
- [ ] สีขนเป็นของรางวัลที่ปลดล็อกทีหลัง (ไม่ให้เลือกตอนเริ่ม)
- [ ] ระบบสุ่มของประดับตกแต่งสัตว์เลี้ยง (ต้องออกแบบกติกาก่อน เช่น ได้จากการเรียน ไม่ใช้เงินจริง) เก็บไว้ดูอีกครั้ง
- [ ] ร่างที่โตขึ้นตามความสนิท (ร่าง 1–3) ในรูปแบบพิกเซลเพื่อสร้างความผูกพัน
- [x] เพิ่มบทพูดให้ครบนิสัยทั้ง 10 แบบ ในทุกช่วงเวลาและเหตุการณ์ (29 ประโยคต่อนิสัย)
- [ ] ระบบรางวัล: เรียนแล้วได้ของแต่งตัวหรือของตกแต่งให้สัตว์เลี้ยง
